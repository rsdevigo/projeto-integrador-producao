Este repositório contém o material didático de apoio da disciplina **Projeto Integrador – Produção**, continuação direta da fase de pré-produção do semestre anterior. ## Visão geral da disciplina

- **Carga horária:** 17 semanas letivas, 1 encontro de 2h15 por semana.
- **Metodologia:** Project-Based Learning e Studio-Based Learning — os encontros presenciais funcionam como checkpoints de desenvolvimento, revisões de progresso e mentorias; o desenvolvimento ocorre principalmente fora da sala de aula.
- **Escopo:** condução do projeto concebido na disciplina de Pré-Produção até um **Vertical Slice** jogável — não um jogo completo.
- **Milestones:** Kickoff → Planejamento → Produção Inicial → Alpha → Produção Intermediária → Beta → Polimento → Apresentação Final.
- **Avaliação:** contínua, valorizando evolução da equipe, organização, cumprimento dos milestones, qualidade da produção, documentação, comunicação e apresentação final.
