## 9. Checklist — Pronta para demonstração?

Marcar todos os itens antes de apresentar a build em sala de aula ou para o professor.

- [ ] A build inicializa sem erros.
- [ ] O fluxo principal do jogo pode ser jogado do início ao fim sem travamentos.
- [ ] Não há problemas críticos em aberto.
- [ ] A identidade visual está coerente em todas as telas.
- [ ] A interface (HUD, menus, textos) está funcional e legível.
- [ ] O áudio (quando aplicável) está funcionando corretamente.
- [ ] Os controles respondem conforme esperado.
- [ ] A build foi testada em pelo menos um dispositivo/máquina fora da máquina de desenvolvimento.
- [ ] Não há elementos de placeholder visíveis que comprometam a demonstração (ex.: texturas quebradas, textos "lorem ipsum").
- [ ] A build foi versionada e está disponível no repositório do projeto.
- [ ] A equipe sabe explicar o que mudou nesta build.

**Status final da build:** ☐ Pronta para demonstração ☐ Necessita ajustes antes da demonstração
